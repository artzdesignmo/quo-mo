# Quo-mo

澳門商業單據工作室 — 報價單 / 發票 / 收據模板系統，專為澳門特區商業用途設計。

Macau business document studio — quotation / invoice / receipt templates for Macau businesses.

**Demo:** https://artzdesignmo.github.io/quo-mo/

## 功能

- **12 套專業模板**：經典深藍、極簡、活力色帶、典雅金、企業藍、網格、柔和、暗黑、葡式花磚、緊湊、創意、正式公函
- **三種單據**：報價單 Quotation / 發票 Invoice / 收據 Receipt
- **三種語言模式**：雙語（繁體中文＋英文）/ 中文 / 英文
- 賣方資訊（中英葡名稱、地址、電話、電郵、Logo 上載）
- 單據編號、日期（YYYY-MM-DD）、有效期限
- Bill To 客戶資訊
- 明細表格：項目、描述、數量、單價（MOP）、折扣、金額（自動計算）
- 總金額＋大寫金額（中文大寫＋英文）
- 支付資訊（銀行轉帳、支票抬頭，可選）
- 備註、授權簽署及公司蓋章欄
- **輸出**：A4 PNG / JPG（2x 高清）、PDF（列印）、JSON 儲存／讀取，草稿自動存於瀏覽器

## 技術

純 HTML + CSS + JavaScript，無框架、無依賴，100% 瀏覽器內運作，離線可用。
